# Дипломная работа: Автоматизация тестирования Кинопоиска

## Описание проекта
Автоматизация API и UI тестов для сайта Кинопоиск.

## API тесты (9 шт)
Покрывают поиск фильмов, негативные сценарии, авторизацию.

## UI тесты (5 шт)
Стабильность ограничена защитой сайта (капча). Перед первым запуском необходимо вручную пройти капчу в открывшемся окне браузера.

## Установка и запуск

```bash
pip install -r requirements.txt
pytest -m api -v      # API тесты
pytest -m ui -v -s    # UI тесты
pytest -v -s          # Все тесты
