# Дипломная работа: Автоматизация тестирования Кинопоиска

## Описание проекта
Автоматизация UI и API тестов для сайта Кинопоиск на основе ручных тест-кейсов из Test IT и Postman.

## Тест-кейсы

### UI тесты 
1. Поиск по названию "Ужасающий"
2. Поиск по обрывку названия
3. Поиск по актеру Тео Джеймс
4. Выбор фильма и просмотр карточки
5. Очистка поисковой строки

### API тесты 
1. Поиск фильма по ID
2. Поиск по неверному эндпоинту
3. Поиск по несуществующему ID
4. Поиск по названию на кириллице
5. Поиск по названию на латинице с ошибкой
