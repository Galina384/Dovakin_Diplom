# Дипломная работа: Автоматизация тестирования Кинопоиска

## Описание проекта
Автоматизация API и UI тестов для сайта Кинопоиск.

## API тесты (9 шт)
Поиск фильмов, негативные данные, авторизацию.

## UI тесты (5 шт)
Сайт имеет защиту от роботизированного вмешательства. При проведении теста выходит капча "Я не робот". Ее необходимо проходить вручную, так как обход безопасности не представляется возможным

## Установка и запуск


pip install -r requirements.txt
pytest -m api -v       API тесты
pytest -m ui -v -s     UI тесты
pytest -v -s           Все тесты

ССылка на финальную курсовую https://dovakin.yonote.ru/doc/otchet-po-testirovaniyu-sajta-kinopoisk-J1Ue9HES8V
