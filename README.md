# Дипломная работа: Автоматизация тестирования Кинопоиска

## Описание проекта
Автоматизация UI и API тестов для сайта Кинопоиск.

## Тест-кейсы

### UI тесты (5 шт)
1. Поиск фильма по названию
2. Поиск с пустым запросом
3. Поиск фильма на английском языке
4. Загрузка главной страницы
5. Проверка наличия кнопки поиска

### API тесты (5 шт)
1. Поиск фильма по ID
2. Поиск по неверному эндпоинту
3. Поиск по несуществующему ID
4. Поиск по названию на кириллице
5. Поиск по названию на латинице с ошибкой
